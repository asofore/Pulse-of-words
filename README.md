# 📖 نبض الكلمات (Nabdh Al-Kalimat)

تطبيق لسطح المكتب والهواتف المحمولة مبني باستخدام لغة **Python** وإطار العمل **Kivy**، يهدف إلى تقديم مجموعة واسعة من الاقتباسات والحكم بأسلوب تصميم داكن وأنيق مريح للعين

---

## 🌟 المميزات (Features)

* **تصميم عصري وداكن (Dark Theme):** واجهة جذابة بخلفية سوداء وإطارات كلاسيكية مريحة للقراءة[span_1](start_span)[span_1](end_span).
* **تصفح سلس:** قائمة منظمة لعرض الاقتباسات والتنقل بينها بسهولة.
* **دعم متعدد المنصات (Cross-Platform):** يعمل على أندرويد (Android)، ويندوز (Windows)، ولينكس (Linux).
* **خفيف وسريع:** يعتمد على مكتبات بايثون الخفيفة لضمان أداء عالٍ واستجابة سريعة.
